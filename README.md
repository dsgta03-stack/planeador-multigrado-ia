# Planeador Multigrado IA — Demo V0.8.2

Demo web desplegable en Railway, sin API de IA de pago.

## Funciones
- Selección de grados 1.º–6.º.
- Contexto y problema escolar.
- Recuperación real desde Supabase.
- Texto oficial PDA visible.
- Máximo 4 PDA por grado.
- Visualización de LTG vinculados.

## Seguridad
No contiene service-role key ni OpenAI API key. La demo solo consulta el endpoint curricular público de solo lectura.
